# Civilization: Enemies of Rome

A Daily Roman Updates mod for Sid Meier's Civilization (DOS), v1.0.

**[Download the latest release](../../releases/latest)**

## How to play
- **Windows:** install [DOSBox](https://www.dosbox.com), then double-click `PLAY_WINDOWS.bat`.
- **Mac:** install [DOSBox-X](https://dosbox-x.com), then double-click `Play Enemies of Rome.command` (or run `dosbox-x -conf dosbox.conf` in Terminal).
- **Linux:** install DOSBox-X and run `PLAY_MAC_LINUX.sh`.

Choose graphics mode 1 (VGA). On the title menu pick **Mediterranean** to play on the map of the Roman world, or **Start a New Game** for a random map.

## What's in it
- 14 peoples, each with a historical leader and a new painted portrait: Romans (Augustus), Carthaginians (Hannibal), Gauls (Vercingetorix), Germans (Arminius), Parthians (Orodes II), Macedonians (Philip V), Dacians (Decebalus), Byzantines (Justinian), Vandals (Genseric), Britons (Boudicca), Goths (Alaric), Sassanids (Shapur I), Pontics (Mithridates VI), Huns (Attila).
- A special unit for each people: Legionary, War Elephants, Gaesatae, Warband, Horse Archers, Helepolis, Falxmen, Dromon, Vandal Raider ship, War Chariot, Huscarl, Clibanarius, Lembus, Hun Raider.
- A Mediterranean map covering Europe, North Africa and the Near East, with every people starting in its homeland.
- Roman-era buildings, wonders and techs (Forum, Basilica, Hadrian's Wall, Pantheon, Library of Alexandria, Roman Roads, Greek Fire...) with new Civilopedia entries.
- Ancient-only tech tree, barbarians as raiders and pirates, and a new story, news and credits.
